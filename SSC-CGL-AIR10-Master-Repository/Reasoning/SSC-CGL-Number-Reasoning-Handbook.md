# Chapter 1: Fundamentals of Number Analogies

## 1.1 What Is a Number Analogy?

A **number analogy** asks you to find a pair (or group) of numbers that share the **same relationship** as a given pair. The format is almost always:

```
A : B  ::  C : ?
```

Read aloud as: **"A is to B, as C is to ?"**

The single most important idea:

> 🎯 **The relationship between A and B is identical to the relationship between C and the answer.**

**Example:**
```
4 : 16  ::  5 : ?
```
Relationship: B = A². So 4 → 16 (4²), therefore 5 → **25** (5²).

## 1.2 The Three Question Formats

| Format | Looks Like | What's Asked |
|--------|-----------|--------------|
| **Pair Analogy** | `7 : 49 :: 8 : ?` | Apply the A→B rule to C |
| **Number Triplet** | `(3, 5, 16)` | Find the rule linking all three; apply to a new triplet |
| **Choose-the-Analogous-Pair** | `Which is like 6:42?` | Pick the option pair with the same logic |

> 📌 **PYQ Note:** Since 2018, SSC CGL has shifted heavily toward **triplet-style** analogies `(a, b, c)` where `c` is built from `a` and `b`. Master Chapters 2–6 and you cover ~70% of analogy questions.

## 1.3 Types of Number Analogy Relationships

There are only **eight families** of relationships. Memorise these — every question is one of them:

| # | Family | Signal | Example |
|---|--------|--------|---------|
| 1 | **Arithmetic** | small, steady change | 12:15 (+3) |
| 2 | **Multiplicative** | B is a multiple of A | 6:42 (×7) |
| 3 | **Square / Square-root** | B ≈ A² or √A | 9:81 |
| 4 | **Cube / Cube-root** | B ≈ A³ | 4:64 |
| 5 | **Product-based (triplet)** | c relates to a×b | (3,4,12) |
| 6 | **Sum/Difference-based** | c = a±b or with constant | (5,3,8) |
| 7 | **Digit-based** | rearranged/summed digits | 23:32 |
| 8 | **Special numbers** | primes, factorials, etc. | 5:120 (5!) |

## 1.4 Common Examiner Intentions

Examiners design analogies to test **four** abilities:

1. **Speed of recognition** — Can you spot ×7 before computing?
2. **Resistance to distractors** — Will you chase a number that doesn't matter?
3. **Flexibility** — Can you switch families when the first guess fails?
4. **Verification discipline** — Do you confirm the rule works on *both* given pairs?

> ⚠️ **Trap:** Examiners deliberately pick numbers where **two rules seem to fit** the first pair, but only **one** fits the second. Always test your rule on the *second* given pair before answering.

## 1.5 How to Identify the Relationship — The 3-Question Probe

When you see `A : B`, silently ask, in order:

1. **"Is B bigger or smaller, and by how much?"**
   - Slightly bigger → addition. Much bigger → multiplication/power.
2. **"Is the ratio clean?"** (B ÷ A a whole number → multiplication)
3. **"Are these recognisable special numbers?"** (squares, cubes, primes)

## 1.6 Step-by-Step Worked Examples

**Example 1:** `8 : 64 :: 9 : ?`
- B much bigger than A → power. 64 = 8². Rule: B = A².
- Verify mindset: confident. Answer = 9² = **81**.

**Example 2:** `7 : 56 :: 6 : ?`
- 56 ÷ 7 = 8 (clean ratio) → ×8. Answer = 6 × 8 = **48**.
- ⚠️ Distractor thought: 56 = 7² + 7 = 49+7? Also true! Test on second pair: 6²+6 = 42 ≠ option if ×8 gives 48. *Check options* (see Ch. 8).

**Example 3 (triplet):** `(2, 3, 7) :: (4, 5, ?)`
- Find rule: 2,3 → 7. Try a+b = 5 ✗. Try a×b+1 = 7 ✓. Verify: 4×5+1 = 21. Answer = **21**.

## 1.7 Common Mistakes (Memorise to Avoid)

| ❌ Mistake | ✅ Fix |
|-----------|-------|
| Testing rule only on first pair | Always verify on the second pair |
| Computing full multiplication early | Check ratio/size *first* |
| Ignoring the answer options | Options often confirm the family fast |
| Forcing addition when numbers are huge | Big jump = power or multiplication |
| Giving up after one failed rule | Cycle through the 8 families |

# Chapter 2: Core Arithmetic Patterns

The foundation. ~30% of all number-analogy questions are pure arithmetic dressed up to look harder.

## 2.1 The Four Operations + Mixed

| Operation | Cue | Triplet form `(a,b,c)` |
|-----------|-----|------------------------|
| Addition | c slightly > a, b | c = a + b |
| Subtraction | c = gap between a, b | c = a − b |
| Multiplication | c much bigger | c = a × b |
| Division | c smaller, clean | c = a ÷ b |
| Mixed | none fit alone | c = (a op b) op constant |

## 2.2 Recognition Speed Drill

> 💡 **Shortcut — the "Size Glance":**
> - c ≈ a + b → **addition**
> - c ≈ a × b → **multiplication**
> - c < both a and b → **subtraction or division**
> Glance at *magnitude* before computing. This alone cuts solving time in half.

## 2.3 For triplet (a, b, c) — find: a+b, a−b, a×b, a÷b

Worked demonstration with **(a=12, b=4)**:
- a + b = 16
- a − b = 8
- a × b = 48
- a ÷ b = 3

Each of these is a *candidate* for what `c` could be. Recognition = matching `c` to one of them.

# Chapter 3: Product-Based Patterns

This is the **heart of modern SSC triplet analogies**. Once `a × b` is "close" to `c`, the real rule is almost always a product *adjusted* by sum or difference.

## 3.1 The Seven Product Templates

| Template | Formula | Example (a=3,b=4) |
|----------|---------|-------------------|
| Pure product | ab | 12 |
| Product + constant | ab + k | ab+1 = 13 |
| Product − constant | ab − k | ab−1 = 11 |
| Product + sum | ab + (a+b) | 12+7 = 19 |
| Product − sum | ab − (a+b) | 12−7 = 5 |
| Product + difference | ab + (a−b) | 12+(−1) = 11 |
| Product − difference | ab − (a−b) | 12−(−1) = 13 |

## 3.2 💡 Recognition Shortcut — "Anchor on the Product"

1. Compute `a × b` mentally (the **anchor**).
2. Measure the **gap** = `c − ab`.
3. Identify the gap:
   - gap = a+b → **ab+(a+b)**
   - gap = −(a+b) → **ab−(a+b)**
   - gap = a−b → **ab+(a−b)**
   - gap = small fixed number across all triplets → **ab ± constant**

> 🎯 **Recognition Cue:** If `c` is "a bit more than a×b," check `a+b` first — it's SSC's favourite.

## 3.3 Solved Examples

**Ex.1:** (3, 5, 23) → ab=15, gap=8=a+b → **ab+(a+b)** ✓
**Ex.2:** (4, 6, 14) → ab=24, gap=−10=−(a+b) → **ab−(a+b)** ✓
**Ex.3:** (7, 2, 19) → ab=14, gap=5=a−b → **ab+(a−b)** ✓
**Ex.4:** (9, 3, 28) → ab=27, gap=1 (constant) → **ab+1** ✓
**Ex.5:** (8, 5, 43) → ab=40, gap=3=a−b → **ab+(a−b)** ✓

## 3.4 Difficulty Progression

| Level | Pattern | Why harder |
|-------|---------|-----------|
| 🟢 Easy | ab | direct |
| 🟡 Medium | ab ± constant | one extra step |
| 🟠 Hard | ab ± (a+b) | two quantities to track |
| 🔴 Expert | ab ± (a−b) with negatives | sign errors common |

## 3.5 Exam Traps

> ⚠️ **Trap 1 — The "+1 vs +sum" confusion:** When a+b happens to equal a small number (e.g., a=1), `ab+(a+b)` looks like `ab+constant`. **Verify on the second triplet** where a+b is large.
> ⚠️ **Trap 2 — Sign of difference:** `a−b` can be negative. (4,6,..) → a−b = −2, so ab+(a−b) = ab−2. Watch the order a−b vs b−a.

# Chapter 4: Squares and Perfect Squares

## 4.1 The Square Family

| Pattern | Formula | (a=3,b=2) |
|---------|---------|-----------|
| Sum of squares | a²+b² | 13 |
| Difference of squares | a²−b² | 5 |
| Square of sum | (a+b)² | 25 |
| Square of difference | (a−b)² | 1 |

> 🔑 Remember the identities: `(a+b)² = a²+2ab+b²` and `a²−b² = (a+b)(a−b)`. The second is a *speed weapon*: 17²−13² = (30)(4) = 120 instantly.

| 10 | 100 | 20 | 400 | 30 | 900 |

## 4.3 💡 Fast Square Tricks

- **Numbers ending in 5:** `(n5)² = n(n+1) | 25`. E.g. 35² = 3×4 |25 = **1225**; 85² = 8×9|25 = **7225**.
- **Near a base (e.g., 50):** 48² = (48−50)... use (50−2)² = 2500 − 200 + 4 = **2304**.
- **Difference of squares:** any a²−b² = (a+b)(a−b). Use it to *recognise* hidden patterns.

## 4.4 🎯 Perfect-Square Recognition (last-digit filter)

A perfect square can **only** end in **0, 1, 4, 5, 6, 9**. Never in 2, 3, 7, 8.
- Sees a number ending in 7? **Not** a perfect square — don't waste time.
- Digital root of a perfect square is always 1, 4, 7, or 9.

## 4.5 PYQ-Style Examples

**Ex.1:** `12 : 144 :: 15 : ?` → square. **225**.
**Ex.2:** (5, 3, 16) → a²−b² = 25−9 = **16** ✓
**Ex.3:** (7, 2, 81) → (a+b)² = 9² = **81** ✓
**Ex.4:** (8, 5, 89) → a²+b² = 64+25 = **89** ✓
**Ex.5:** `289 : 17 :: 529 : ?` → square-root. √529 = **23**.

# Chapter 6: Modified Number Relationships

SSC's "second-level" difficulty: the operands are **shifted** before combining.

## 6.1 The Modification Templates

| Template | Meaning | (a=5,b=4) |
|----------|---------|-----------|
| (a+1)(b−1) | shift up/down then multiply | 6×3 = 18 |
| (a−1)(b+1) | shift down/up | 4×5 = 20 |
| (a+1)(b−2) | asymmetric shift | 6×2 = 12 |
| (a−2)(b+1) | asymmetric shift | 3×5 = 15 |
| (a+1)(b+1) | both up | 6×5 = 30 |
| (a−1)(b−1) | both down | 4×3 = 12 |

## 6.2 Why Examiners Use These

> 📌 **PYQ Note:** Plain `a×b` became "too easy" and over-practised. From ~2019, SSC introduced **±1 / ±2 shifts** so that the product *looks* wrong unless you spot the shift. They reward candidates who **test the neighbours** of a and b.

## 6.3 💡 How to Detect Quickly

1. Compute `a×b` (anchor).
2. If `c` is off by a value equal to `a`, `b`, `a+b`, or `a+b+1` → a shift is in play (because `(a+1)(b−1) = ab − a + b − 1`).
3. Quick expansions to memorise:
   - `(a+1)(b−1) = ab + b − a − 1`
   - `(a−1)(b+1) = ab + a − b − 1`
   - `(a+1)(b+1) = ab + a + b + 1`
   - `(a−1)(b−1) = ab − a − b + 1`

> 🎯 **Recognition Cue:** Gap from `ab` looks like `±a ±b ±1` → it's a modified product.

## 6.4 Solved Examples
**Ex.1:** (5, 4, 18) → (a+1)(b−1) = 6×3 = **18** ✓
**Ex.2:** (7, 3, 24) → (a−1)(b+1) = 6×4 = **24** ✓
**Ex.3:** (6, 5, 14) → (a+1)(b−2)? = 7×3 = 21 ✗; (a−2)(b+1)? = 4×6 = 24 ✗; (a−1)(b−1) = 5×4 = 20 ✗… (a+1)(b−... try ab−(a+... ) Actually 6×5=30, gap −16. Test (a−2)(b−1)=4×4=16? No. → This shows verification discipline: not every triplet is modified-product; fall back to other families.
**Ex.4:** (8, 6, 63) → (a+1)(b+1)? = 9×7 = **63** ✓
**Ex.5:** (9, 5, 32) → (a−1)(b−1) = 8×4 = **32** ✓

# Chapter 7: Constant Difference and Hidden Difference Logic

Some triplets aren't built by combining `a` and `b` — instead, the **three numbers themselves** are linked by a fixed difference, or `c` is derived from a difference of `a` and `b`.

## 7.1 The Examples Decoded

Consider the given set:
```
(79, 58, 62)     (54, 33, 37)     (66, 45, 49)
```

**Step 1 — scan column-wise / within-row differences:**

| Triplet | a−b | c−b | a−c |
|---------|-----|-----|-----|
| (79, 58, 62) | **21** | 4 | 17 |
| (54, 33, 37) | **21** | 4 | 17 |
| (66, 45, 49) | **21** | 4 | 17 |

🎯 **The hidden logic:** In every triplet, `a − b = 21` and `c = b + 4`. The numbers *look* unrelated, but two **constant differences** govern all three rows.

> 💡 **Shortcut — "Difference Fingerprint":** When `a` and `b` look random, compute `a − b` for each given triplet. If it's the **same constant**, you've found the rule. Then check how `c` relates to `a` or `b` (here `c = b + 4`).

## 7.2 Constant Differences

A **constant difference** means the gap between two positions is identical across all triplets. SSC uses this to make triplets look chaotic while being mechanically simple.

## 7.3 Secondary Differences

When the *first* differences aren't constant, take the **difference of the differences**:
- Series 2, 5, 10, 17 → first diff 3,5,7 → second diff 2,2,2 (constant) → it's `n²+1`.

> 🎯 **Recognition Cue:** First differences forming 3,5,7,9… (odd numbers) → underlying **square** pattern.

## 7.4 Column-Wise Logic (for triplets presented as a list)

When you see multiple triplets stacked, read **down each column**, not just across rows:

```
Column A: 79, 54, 66
Column B: 58, 33, 45
Column C: 62, 37, 49
```
Check: A−B per row (constant 21), B→C per row (+4). Column thinking exposes patterns that row thinking misses.

## 7.5 Solved Examples
**Ex.1:** (45, 30, 33): a−b=15, c=b+3. Apply to (60, 45, ?): a−b=15 ✓, c=b+3=**48**.
**Ex.2:** (88, 70, 75): a−b=18, c=b+5. (52, 34, ?) → **39**.
**Ex.3:** Series 4, 7, 12, 19, ?: first diffs 3,5,7,9 → next 9 → **28**.

# Chapter 8: Distractor Number Techniques

The single most under-taught skill. Examiners insert numbers that are **decorative** — not part of the actual rule — to consume your time.

## 8.1 The Core Insight

Look at:
```
(7, 8, 48)        (6, 8, 42)
```
A beginner tries `a × b`: 7×8 = 56 ≠ 48; 6×8 = 48 ≠ 42. Confusion!

**Now ignore the middle number and look at a and c:**
- 7 → 48? Try... no clean link. Try `b × (a−1)`: 8×6 = 48 ✓; 8×... wait.
- Better: `(a−1) × b`: (7−1)×8 = 48 ✓ and (6−1)×... = 5×8 = 40 ✗.

Re-examine with the relationship `b × (something)`:
- 48 = 8 × 6, and 6 = 7−1 → `b(a−1)` = 48 ✓
- 42 = ... 6 × 7 → here `a × b` with roles... = 42 = 6×7. Note 7 = 8−1 = b−1 → `a(b−1)` = 6×7 = 42 ✓

🎯 **Lesson:** The *form* shifted, but the principle holds — **one operand is "decorated" (the +1/−1), and you must test which number is the real driver.** A purely mechanical `a×b` fails; isolating the genuine relationship succeeds.

> 💡 **Shortcut:** When the obvious operation misses by a *clean small factor or ±1 pattern*, suspect that one number is a **distractor / decorated operand**. Strip it down to its neighbour.

## 8.2 Ignoring Irrelevant Numbers

Procedure:
1. Try the rule using only **two** of the three numbers.
2. If two numbers fully explain the third, the "extra" interplay was a distractor.
3. Common form: `c` depends only on `a` (e.g., c = a² + small), and `b` is noise.

## 8.3 Eliminating Misleading Assumptions

> ⚠️ **Trap:** A "nice" number like 8 or 100 *invites* you to multiply/divide by it. Examiners place round numbers as bait. Confirm relevance before using.

## 8.4 Option-Based Verification (Back-Solving)

In MCQ format, you have 4 options. Use them:
1. Find the rule from the given pair (even if shaky).
2. Apply to each option; the one matching the pattern family wins.
3. If two options survive, recompute the rule on the *second* given example to break the tie.

> 📌 **PYQ Note:** ~15% of SSC analogy questions are *only* solvable efficiently by back-solving from options. Treat options as **part of the question**, not an afterthought.

## 10.2 🎯 Prime Recognition Test (fast)

To check if n < 121 is prime, test divisibility only by **2, 3, 5, 7** (primes ≤ √n).
- Even → not prime (except 2).
- Digit sum divisible by 3 → not prime (except 3).
- Ends in 0/5 → divisible by 5 (except 5).
- Else test 7.

## 10.3 Prime Positions & Prime-Based Analogies

# Chapter 11: Missing Number Questions

Numbers arranged in a **figure** (triangle, circle, square, grid). Find the missing one by deducing the figure's internal rule.

## 11.1 Triangle Patterns

```
        (A)
       /   \
     (B) — (C)
        (X)        ← X in centre
```
Common rules: `X = A+B+C`, `X = A×B×C`, `X = (A+B+C)/k`, `X = A²+B²+C²`.

**Ex.1:** Corners 2,3,4; centre 9 → sum. Another triangle 5,1,2 → centre **8**.
**Ex.2:** Corners 3,4,2; centre 24 → product. 2,3,5 → centre **30**.

## 11.2 Circle Patterns

```
     ( A )
   (B)( X )(C)     ← divided into sectors
     ( D )
```
Rule often: opposite sectors multiply/add to equal value, or centre = function of rim.

**Ex.:** Rim 6,4,3,2; centre 15 → (6+4+3+2)=15 ✓.

## 11.3 Square (4-corner + centre) Patterns

```
A ---- B
|  X   |
C ---- D
```
Rules: `X = (A+D)−(B+C)`, `X = (A×D)/(B×C)`, diagonal products equal.

**Ex.:** A=8,B=4,C=2,D=6, X=? with rule (A×D)−(B×C) = 48−8 = **40**.

## 11.4 Grid (3×3 Matrix) Patterns

```
| 2 | 3 | 5 |
| 4 | 5 | 9 |
| 6 | 7 | ? |
```
Rule: col3 = col1 + col2 → ? = 6+7 = **13**.

## 11.5 💡 Universal Approach to Missing-Number Figures
1. Identify the **complete** cells first.
2. Test the four basics (sum, product, difference, ratio) on a *complete* example.
3. Extend the confirmed rule to the missing cell.
4. Watch for **diagonal** and **across-figure** relations, not just adjacency.

# Chapter 12: Number Classification (Odd One Out)

Identify the number that **doesn't share** the common property.

## 12.1 The Classification Checklist

Run the group through these tests **in order**:

| Test | Property | Spot the outlier |
|------|----------|------------------|
| Prime | all prime? | one composite breaks it |
| Square | all perfect squares? | one non-square |
| Cube | all perfect cubes? | one non-cube |
| Even/Odd | parity | the lone even/odd |
| AP | constant difference | the one breaking the step |
| GP | constant ratio | the one breaking the ratio |
| Divisibility | all ÷ k | the indivisible one |

## 12.2 💡 Strategy

> 💡 **Shortcut:** First glance for the **most striking shared feature** (all even? all end in same digit? all squares?). The odd one usually breaks the *most obvious* feature. Don't over-think simple sets.

## 12.3 Solved Examples
**Ex.1:** 11, 13, 15, 17 → all prime except **15** (=3×5).
**Ex.2:** 16, 25, 36, 40 → squares except **40**.
**Ex.3:** 27, 64, 100, 125 → cubes except **100** (it's a square).
**Ex.4:** 3, 6, 12, 24, 50 → GP (×2) except **50**.
**Ex.5:** 14, 28, 42, 55 → multiples of 7 except **55**.

## 12.4 ⚠️ Multi-Property Traps
> ⚠️ **Trap:** 64 is *both* a square (8²) and a cube (4³). In a set of cubes, 64 fits; in a set of squares, it also fits — so it's never the odd one when those are the test. Examiners exploit such "dual" numbers (1, 64, 729) to mislead.

# Chapter 13: Number Series

Find the next term (or missing term) in a sequence. ~10–15% of SSC reasoning.

## 13.1 The Series Families

| Family | Rule | Example |
|--------|------|---------|
| Arithmetic (AP) | +constant | 3,7,11,15 (+4) |
| Geometric (GP) | ×constant | 2,6,18,54 (×3) |
| Alternating | two interleaved rules | 1,10,2,20,3,30 |
| Square | n² based | 1,4,9,16,25 |
| Cube | n³ based | 1,8,27,64 |
| Mixed | combination | ×2+1: 3,7,15,31 |
| Difference-of-difference | 2nd diff constant | 2,5,10,17 |

## 13.2 🎯 Fast Recognition Techniques

> 💡 **The Difference Ladder:**
> 1. Write the gaps between consecutive terms.
> 2. **Constant gap** → AP.
> 3. **Gaps forming their own pattern** (×, +): nested rule.
> 4. **Gaps = 3,5,7,9** → squares underneath.
> 5. If ratios are constant instead → GP.

> 🎯 **Cue:** Rapid explosion (small → huge fast) → GP, cubes, or ×n+k. Gentle climb → AP or squares.

# Chapter 14: Matrix and Non-Verbal Number Patterns

Numbers in a **matrix**; rows/columns/diagonals hide a rule.

## 14.1 2×2 Matrices
```
| a | b |
| c | d |
```
Common rule: `d = (a+b+c)` or `a×d = b×c` (constant cross-product).

**Ex.:** `|3|4|` / `|5|?|` with rule a+b+c → ? = 12. Or with a×d=b×c → d = (4×5)/3.

## 14.2 3×3 Matrices
```
| 2 | 3 | 5 |
| 4 | 1 | 5 |
| 6 | 2 | ? |
```
🎯 Test: **col1 + col2 = col3** → row3: 6+2 = **8**.

## 14.3 Hidden Row Logic
Each row is self-contained: `(1st × 2nd) − 3rd = constant`, or `3rd = 1st² − 2nd`.

**Ex.:** Rows (3, 2, 7),(4, 3, 13),(5, 4, ?) → rule a²−b → 25−4 = **21**.

## 14.4 Hidden Column Logic
Read **down** columns. `col3 = col1 × col2`, or each column is an AP/GP.

**Ex.:**
```
| 2 | 8 |
| 4 | 16 |
| 6 | ? |
```
Column2 = column1 × 4... but row-wise also ×4 → ? = 24, or column2 GP ×2 → 32. *Confirm with a complete column.*

## 14.5 💡 Matrix Strategy
1. Pick the **most complete row/column** to discover the rule.
2. Verify on a **second** complete line.
3. Apply to the missing cell.
4. If rows fail, **rotate to columns**, then **diagonals**.

# Chapter 16: SSC CGL Speed-Solving Framework

## 16.1 The Universal Decision Tree

When you see a triplet `(a, b, c)` or pair `A : B`, run this **10-checkpoint cascade**. Stop at the first that fits — then **verify on the second example**.

```
START: look at size of c relative to a, b
│
├─ 1. c ≈ a+b?            → ADDITION
├─ 2. c = |a−b|?          → SUBTRACTION
├─ 3. c = a×b exactly?    → MULTIPLICATION
├─ 4. c = a÷b clean?      → DIVISION
│
├─ 5. c near a×b?         → PRODUCT ± SUM / ± DIFF  (gap = a+b or a−b?)
│
├─ 6. c is large & "clean"?
│     ├─ perfect square?  → a², a²±b², (a±b)²
│     └─ perfect cube?    → a³, a³±b³, cube±1
│
├─ 7. c off by ±a/±b/±1 from a×b? → MODIFIED (a±1)(b±1)
│
├─ 8. a,b look random, same a−b across rows? → CONSTANT DIFFERENCE
│
├─ 9. one number explains c alone? → DISTRACTOR (ignore the noise)
│
└─10. digits rearranged / summed? → DIGIT-BASED
      still nothing → PRIME / SPECIAL / BACK-SOLVE FROM OPTIONS
```

## 16.2 🧠 Visual Memory Aid — "SAMS-PCMD"

Memorise the order with this mnemonic:

> **S**ize → **A**dd → **M**ultiply → **S**quare → **P**roduct±sum → **C**ube → **M**odified → **D**istractor

*"Some Awesome Maths Students Pass Cgl Most Definitely."*

## 16.3 ⏱️ Exam-Hall Strategy
1. **8-second rule:** if no family fits in 8 seconds, **mark and skip**. Return later.
2. **Verify-once discipline:** always test the rule on the *second* given pair/triplet before committing.
3. **Use options early** on hard ones — back-solving (Ch.8) is faster than deriving.
4. **Anchor on the product** for any triplet where c is moderately large (Ch.3).
5. **Last-digit filters** for squares/cubes (Ch.4, 5) save full computation.
6. **Don't fight a number** — if it won't fit, it's probably a distractor (Ch.8).

# 🏁 Final Revision Capsule

## The 8 Families (never forget)
1. Arithmetic (±) 2. Multiplicative (×÷) 3. Product±sum/diff 4. Squares (a²±b², (a±b)²) 5. Cubes (a³±b³, cube±1) 6. Modified products (a±1)(b±1) 7. Digit-based 8. Special (prime/factorial/triangular).

## The 5 Iron Rules
1. **Glance at size before computing.**
2. **Anchor on a×b** for moderate-size triplets.
3. **Verify on the second example — always.**
4. **A number that won't fit is probably a distractor.**
5. **8 seconds, then skip and return.**

## Must-Memorise Tables
- Squares 1–30 · Cubes 1–15 · Primes <100 · Fake primes (51, 57, 87, 91, 119) · Pythagorean triples (3-4-5, 5-12-13, 7-24-25, 8-15-17, 9-40-41, 20-21-29).

## Last-Digit Filters
- **Square** ends only in 0,1,4,5,6,9.
- **Cube** root last digit: 2↔8, 3↔7, 0/1/4/5/6/9 unchanged.
