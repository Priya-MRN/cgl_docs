# Analogy & Classification — Solved Question Bank

> Quick links: [Reasoning Index](README.md) · [Reasoning Cheat Sheet](../Cheat-Sheets/Reasoning_Cheat_Sheet.md)

## Key Concepts
- **Analogy** = find the same relationship in the second pair as in the first.
- Letter positions: A=1, B=2, … Z=26. Track the *gap* between letters.
- **Classification (odd-one-out)** = three items share a property; one breaks it.
- Common relations: ±gap, squares/cubes, opposite letters (A↔Z), category/type.
- Always test number patterns: prime, square, cube, multiples, ±constant.

## EASY

**Q1.** AB : CD :: EF : ?
(a) GH  (b) FG  (c) HI  (d) GI
**Answer: (a) GH**
*Solution:* Each pair is two consecutive letters, and the next pair starts right after the previous. After EF comes GH.

**Q2.** 2 : 8 :: 3 : ?
(a) 9  (b) 18  (c) 27  (d) 12
**Answer: (c) 27**
*Solution:* 2 → 2³ = 8, so 3 → 3³ = 27. The relation is cube of the number.

**Q3.** Cat : Kitten :: Dog : ?
(a) Cub  (b) Puppy  (c) Calf  (d) Foal
**Answer: (b) Puppy**
*Solution:* A young cat is a kitten; the young of a dog is a puppy.

**Q4.** Find the odd one out: 3, 5, 7, 9, 11
(a) 3  (b) 5  (c) 9  (d) 11
**Answer: (c) 9**
*Solution:* 3, 5, 7, 11 are prime numbers; 9 = 3 × 3 is composite, so it is the odd one.

**Q5.** Find the odd one out: Rose, Lotus, Lily, Mango
(a) Rose  (b) Lotus  (c) Lily  (d) Mango
**Answer: (d) Mango**
*Solution:* Rose, Lotus and Lily are flowers; mango is a fruit.

## MEDIUM

**Q1.** ACE : BDF :: GIK : ?
(a) HJL  (b) HIK  (c) FHJ  (d) HJM
**Answer: (a) HJL**
*Solution:* Each letter shifts +1: A→B, C→D, E→F. Apply to GIK: G→H, I→J, K→L = HJL.

**Q2.** 7 : 50 :: 9 : ?
(a) 80  (b) 82  (c) 81  (d) 72
**Answer: (b) 82**
*Solution:* 7² + 1 = 50, so 9² + 1 = 81 + 1 = 82.

**Q3.** BDF : 246 :: CEG : ?
(a) 357  (b) 246  (c) 358  (d) 246
**Answer: (a) 357**
*Solution:* Replace each letter by its position: C=3, E=5, G=7 → 357 (matching B=2, D=4, F=6 → 246).

**Q4.** Find the odd one out: 16, 25, 36, 49, 50
(a) 16  (b) 36  (c) 49  (d) 50
**Answer: (d) 50**
*Solution:* 16, 25, 36, 49 are perfect squares (4², 5², 6², 7²); 50 is not a perfect square.

**Q5.** Find the odd one out: DF, GI, JL, MN
(a) DF  (b) GI  (c) JL  (d) MN
**Answer: (d) MN**
*Solution:* In DF, GI, JL the two letters have a gap of one skipped letter (D_F, G_I, J_L). MN are consecutive (no gap), so it differs.

**Q6.** AZ : BY :: CX : ?
(a) DV  (b) DW  (c) EW  (d) DX
**Answer: (b) DW**
*Solution:* First letters increase A→B→C→D; second letters are their opposites (A↔Z, B↔Y, C↔X, D↔W). After CX comes DW.

## HARD

**Q1.** 5 : 36 :: 6 : ?
(a) 49  (b) 48  (c) 50  (d) 47
**Answer: (a) 49**
*Solution:* 5 → (5+1)² = 36, so 6 → (6+1)² = 7² = 49.

**Q2.** BEH : KNQ :: TWZ : ?
(a) CFI  (b) CFH  (c) DGJ  (d) BEH
**Answer: (a) CFI**
*Solution:* Within each triplet the gap is +3 (B,E,H). Between triplets each letter jumps +9: B+9=K, E+9=N, H+9=Q. Apply +9 to T,W,Z with wrap-around (Z=26, +9 → 35−26=9=I): T+9=C(20+9=29−26=3), W+9=F, Z+9=I → CFI.

**Q3.** Find the odd one out: 121, 144, 169, 180, 196
(a) 121  (b) 169  (c) 180  (d) 196
**Answer: (c) 180**
*Solution:* 121=11², 144=12², 169=13², 196=14² are perfect squares; 180 is not.

**Q4.** Find the odd one out: Triangle, Pentagon, Hexagon, Circle
(a) Triangle  (b) Pentagon  (c) Hexagon  (d) Circle
**Answer: (d) Circle**
*Solution:* Triangle, pentagon and hexagon are polygons made of straight sides; a circle has no straight sides/vertices.

## SSC PYQ PATTERN (SSC CGL pattern)

**Q1.** Select the option that is related to the third term in the same way as the second is to the first: 8 : 64 :: 11 : ?
(a) 100  (b) 121  (c) 144  (d) 132
**Answer: (b) 121**
*Solution:* 8² = 64, so 11² = 121. The relation is square of the number.

**Q2.** Select the odd one: 23, 29, 31, 33, 37
(a) 29  (b) 31  (c) 33  (d) 37
**Answer: (c) 33**
*Solution:* 23, 29, 31, 37 are primes; 33 = 3 × 11 is composite.

**Q3.** PRT : QSU :: ? : KMO
(a) JLN  (b) LNP  (c) IKM  (d) JKM
**Answer: (a) JLN**
*Solution:* The second triplet is each letter of the first +1. To get KMO by +1, the original must be J(K−1)L(M−1)N(O−1) = JLN.

**Q4.** Select the option related to the fourth like the second is to the first: Doctor : Hospital :: Teacher : ?
(a) Library  (b) School  (c) Student  (d) Book
**Answer: (b) School**
*Solution:* A doctor works in a hospital; a teacher works in a school (workplace relation).

### 🔑 Trick Box
- For number analogies, test in order: ±k, ×k, square, cube, n²±1, n³±1.
- For letters, write A=1…Z=26 and compare the *gaps*, not the letters themselves.
- "Opposite letter" trick: letter + its pair always sums to 27 (A+Z, B+Y…).
- In classification, three share a rule (prime, square, category) — find the rule, then the breaker.

> Practise spotting the relationship before looking at options — options can mislead.
