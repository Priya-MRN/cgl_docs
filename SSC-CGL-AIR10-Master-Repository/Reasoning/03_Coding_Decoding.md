## Key Concepts
- **Letter-shift**: each letter moves a fixed number of places (e.g. +1, +2, −3).
- **Number coding**: letters replaced by their positions (A=1…Z=26) or by a formula.
- **Symbol coding**: each letter maps to a symbol; decode letter-by-letter.
- **Reverse coding**: the word is written backwards, sometimes with a shift added.
- Always find the rule from the given example, then apply it consistently.

## EASY

**Q1.** If CAT is coded as DBU, then DOG is coded as?
(a) EPH  (b) EPF  (c) FPH  (d) EOH
**Answer: (a) EPH**
*Solution:* Each letter shifts +1: C→D, A→B, T→U. So D→E, O→P, G→H = EPH.

**Q2.** If A=1, B=2, then CAB = ?
(a) 312  (b) 321  (c) 132  (d) 213
**Answer: (a) 312**
*Solution:* C=3, A=1, B=2 → 312.

**Q3.** If RED is coded as FQ... no — if SUN is written backwards, it becomes?
(a) NUS  (b) UNS  (c) SNU  (d) NSU
**Answer: (a) NUS**
*Solution:* Reverse the letters of S-U-N to get N-U-S.

**Q4.** If BIG is coded as CJH, then SAD is coded as?
(a) TBE  (b) TBD  (c) TCE  (d) RBE
**Answer: (a) TBE**
*Solution:* Each letter +1: B→C, I→J, G→H. So S→T, A→B, D→E = TBE.

**Q5.** If MAN is coded as 13-1-14, then CAB = ?
(a) 3-1-2  (b) 3-2-1  (c) 1-3-2  (d) 2-1-3
**Answer: (a) 3-1-2**
*Solution:* Letters are coded as their positions: C=3, A=1, B=2 → 3-1-2.

## MEDIUM

**Q1.** If COLD is coded as DPME, then WARM is coded as?
(a) XBSN  (b) XBSM  (c) XBRN  (d) WBSN
**Answer: (a) XBSN**
*Solution:* Each letter +1: C→D, O→P, L→M, D→E. So W→X, A→B, R→S, M→N = XBSN.

**Q2.** If FACE is coded as 6-1-3-5, then HEAD = ?
(a) 8-5-1-4  (b) 8-4-1-5  (c) 8-5-4-1  (d) 7-5-1-4
**Answer: (a) 8-5-1-4**
*Solution:* Letter positions: H=8, E=5, A=1, D=4 → 8-5-1-4.

**Q3.** If LAMP is coded as KZLO (each letter −1), then DESK = ?
(a) CDRJ  (b) CDRK  (c) CERJ  (d) CDSJ
**Answer: (a) CDRJ**
*Solution:* Each letter −1: D→C, E→D, S→R, K→J = CDRJ.

**Q4.** In a code, TIGER is written as RGZCP. The rule is?
(a) −2 each  (b) +2 each  (c) reverse  (d) −1 each
**Answer: (a) −2 each**
*Solution:* T→R, I→G, G→E, E→C, R→P — every letter shifts back by 2.

**Q5.** If ROAD is coded as DAOR, then TIME is coded as?
(a) EMIT  (b) MEIT  (c) ITEM  (d) EMTI
**Answer: (a) EMIT**
*Solution:* The code reverses the word: ROAD→DAOR, so TIME→EMIT.

**Q6.** If 'sky' = 'mp', 'is' = 'rq', then in this symbol code, the symbol for a letter is consistent. If A→@, B→#, C→$, then CAB = ?
(a) $@#  (b) @#$  (c) #@$  (d) $#@
**Answer: (a) $@#**
*Solution:* Map each letter to its symbol: C→$, A→@, B→# → $@#.

## HARD

**Q1.** If GARDEN is coded as HBSEFO, then FLOWER is coded as?
(a) GMPXFS  (b) GMPXFR  (c) GNPXFS  (d) GMQXFS
**Answer: (a) GMPXFS**
*Solution:* Each letter +1: G→H, A→B, R→S, D→E, E→F, N→O. So F→G, L→M, O→P, W→X, E→F, R→S = GMPXFS.

**Q2.** If in a code A=2, B=4, C=6 (position × 2), then the code for DEF (sum) = ?
(a) 30  (b) 32  (c) 28  (d) 34
**Answer: (a) 30**
*Solution:* D=4×2=8, E=5×2=10, F=6×2=12; sum = 8+10+12 = 30.

**Q3.** If MONKEY is coded as XDJMNL (reverse then −1 each), then check the rule on the first letter. Y reversed is first → Y−1 = X. The code for TIGER (reverse then −1) = ?
(a) QDFHS  (b) QDFGS  (c) QCFHS  (d) PDFHS
**Answer: (a) QDFHS**
*Solution:* Reverse TIGER → REGIT; subtract 1 from each: R→Q, E→D, G→F, I→H, T→S = QDFHS.

**Q4.** If 'CAT' = 24 and 'DOG' = 26 using sum of letter positions, what is the sum for 'PEN'?
(a) 35  (b) 36  (c) 34  (d) 37
**Answer: (a) 35**
*Solution:* P=16, E=5, N=14; 16+5+14 = 35. (Check: C+A+T = 3+1+20 = 24 ✓, D+O+G = 4+15+7 = 26 ✓.)

## SSC PYQ PATTERN (SSC CGL pattern)

**Q1.** In a certain code, PAPER is written as SDSHU. How is MOTHER written in that code?
(a) PRWKHU  (b) PRWHKU  (c) PRWKGU  (d) QRWKHU
**Answer: (a) PRWKHU**
*Solution:* Each letter +3: P→S, A→D, P→S, E→H, R→U. Apply to MOTHER: M→P, O→R, T→W, H→K, E→H, R→U = PRWKHU.

**Q2.** If BAT is coded as 2120, where each letter = position written together... actually BAT = B(2)A(1)T(20) = 2-1-20. What is COW?
(a) 3-15-23  (b) 3-14-23  (c) 3-15-22  (d) 2-15-23
**Answer: (a) 3-15-23**
*Solution:* C=3, O=15, W=23 → 3-15-23.

**Q3.** In a code language, if NORTH is written as EASTH... ignore; if DELHI is coded by reversing as IHLED, then MUMBAI is coded as?
(a) IABMUM  (b) IABMMU  (c) IBAMUM  (d) IAMBUM
**Answer: (a) IABMUM**
*Solution:* Reverse M-U-M-B-A-I → I-A-B-M-U-M = IABMUM.

**Q4.** If RAIN is coded as SBJO, what is the code for CLOUD?
(a) DMPVE  (b) DMPVD  (c) DNPVE  (d) DMQVE
**Answer: (a) DMPVE**
*Solution:* Each letter +1: R→S, A→B, I→J, N→O. So C→D, L→M, O→P, U→V, D→E = DMPVE.

### 🔑 Trick Box
- First decode the *given* example fully to identify the exact rule (+k, −k, reverse, position).
- Keep an A=1…Z=26 strip handy; most number codes are just letter positions.
- For "reverse" codes, write the word backwards first, then apply any shift.
- If a shift wraps past Z, subtract 26 (e.g. Z+3 = 29−26 = 3 = C).

> Verify the rule on every letter of the example before trusting it.
