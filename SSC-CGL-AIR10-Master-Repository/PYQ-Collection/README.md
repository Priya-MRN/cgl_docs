## 🏷️ How the Repeat-Probability Tags Work

Each question carries a tag estimating **how often that pattern recurs** across SSC CGL papers in 2021–2025:

| Tag | Meaning | What to do |
|---|---|---|
| 🔴 **High Repeat** | This pattern appears in *almost every* CGL cycle. Near-guaranteed marks. | Master it cold. Aim for under-30-second solves. |
| 🟡 **Medium Repeat** | Shows up in *most* cycles, often as 1–2 questions. | Know the method; don't get stuck. |
| 🟢 **Low Repeat** | Appears occasionally / as a curveball. | Learn the trick, but don't over-invest. |

> Tags reflect *pattern frequency*, not difficulty. A 🔴 High Repeat question can still be Easy — that's exactly why it's worth nailing.

## How to Use

1. **Pick one bank.** Work through it sub-topic by sub-topic.
2. **Prioritise 🔴 High Repeat** questions on your first pass — they are the highest-yield marks.
3. **Re-solve missed questions** after a day. Spaced repetition beats re-reading.
4. **Route weak topics** back to the relevant Master Bank (Quant / Reasoning / English / Static-GK) for theory.
