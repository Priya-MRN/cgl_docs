# SSC CGL Square & Calculation Tricks Cheat Sheet

## Core Tricks
- Difference of Squares: a²-b²=(a-b)(a+b)
- Square Near 100: (100±x)²
- Square Near 200: (200±x)²
- Number Ending in 5: n5² = n(n+1) followed by 25
