## Alphabet Positions (memorize)
```
A=1  B=2  C=3  D=4  E=5  F=6  G=7  H=8  I=9  J=10 K=11 L=12 M=13
N=14 O=15 P=16 Q=17 R=18 S=19 T=20 U=21 V=22 W=23 X=24 Y=25 Z=26
```
- Opposite (EJOTY trick): A↔Z, B↔Y … sum of pair = **27**
- EJOTY: E=5, J=10, O=15, T=20, Y=25 (quick anchors)
- Reverse position of letter = `27 − position`

## Coding-Decoding
- Letter-shift: find constant difference (+1, −2, +3…)
- Number coding: map each letter to position
- Look for: forward/backward shift, reverse word, opposite letter, sum of positions
- "If +1 forward" → A=B; "If reverse order" → A=Z

## Analogy
- Identify relation: synonym, antonym, part-whole, worker-tool, cause-effect, square/cube, position-shift
- Numbers: check ±, ×, square, cube, prime, factor pattern

## Number / Letter Series
- Differences: constant, increasing AP, ×2, squares (1,4,9,16), cubes (1,8,27), primes (2,3,5,7,11)
- Alternating series → split odd & even positions
- Fibonacci-type: each = sum of previous two

## Blood Relations
- Maternal = mother's side; Paternal = father's side
- "Pointing": break sentence at "is", solve from the named person backward
- Coded (A+B = A is father of B; A−B; A×B): decode symbol table first

## Direction Sense
- Default facing: N up, S down, E right, W left
- Right turn = clockwise; Left turn = anticlockwise
- Shortest distance = `√(x² + y²)` (Pythagoras on net displacement)
- Shadow: sunrise (morning) shadow → West; evening → East; noon → no shadow

## Syllogism
- "All A are B" → some B are A (reverse possible)
- "No A is B" → No B is A (definite)
- "Some A are B" → some B are A; "Some A are not B" → no reverse
- Use Venn; conclusion true only if true in **every** diagram
- Either-Or case: two conclusions, both individually false but complementary (same subject-predicate, one positive one negative)

## Seating / Puzzles
- Circle facing centre: left = clockwise; facing outside: left = anticlockwise
- Draw the diagram; fix the most-constrained clue first
- Linear: note "immediate" vs "somewhere" left/right

## Venn Diagram
- Identify which sets overlap logically (Dog–Animal–Cat: animal contains both, dog & cat separate)

## Non-Verbal
- **Mirror image:** left-right reversal (vertical mirror). Letters symmetric about vertical axis unchanged: A H I M O T U V W X Y
- **Water image:** top-bottom reversal. Unchanged: C D E H I K O X B (about horizontal axis)
- **Paper folding:** punched holes appear symmetric about each fold line
- **Embedded figure:** the simple figure hides inside the complex one, same orientation/size
- **Counting figures:** count systematically (single, double, triple combinations)

## Statement & Conclusion / Assumption
- Conclusion must **follow logically** from statement alone — no outside knowledge
- Assumption = something taken for granted, implicit in the statement

## Data Sufficiency
- Check each statement alone, then together; choose minimal sufficient set
