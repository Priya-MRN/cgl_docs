## Key Formulas

- `a² − b² = (a + b)(a − b)`
- `(a + b)² = a² + 2ab + b²`
- `(a − b)² = a² − 2ab + b²`
- `(a + b)² + (a − b)² = 2(a² + b²)`
- `(a + b)² − (a − b)² = 4ab`
- `a³ + b³ = (a + b)(a² − ab + b²) = (a + b)³ − 3ab(a + b)`
- `a³ − b³ = (a − b)(a² + ab + b²) = (a − b)³ + 3ab(a − b)`
- `a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)`
- If `a + b + c = 0` then `a³ + b³ + c³ = 3abc`
- If `a + 1/a = x` then `a² + 1/a² = x² − 2` and `a³ + 1/a³ = x³ − 3x`
- If `a − 1/a = x` then `a² + 1/a² = x² + 2` and `a³ − 1/a³ = x³ + 3x`

## EASY

**Q1.** If `a + b = 7` and `ab = 12`, find `a² + b²`.
(a) 25  (b) 49  (c) 37  (d) 24
**Answer: (a) 25**
*Solution:* `a² + b² = (a + b)² − 2ab = 7² − 2(12) = 49 − 24 = 25`.

🔑 *Trick:* Always convert sums of squares using `(a+b)² − 2ab` — never solve for a and b separately.

**Q2.** Simplify `(103)² − (97)²`.
(a) 1200  (b) 1500  (c) 600  (d) 2400
**Answer: (a) 1200**
*Solution:* `a² − b² = (a + b)(a − b) = (103 + 97)(103 − 97) = 200 × 6 = 1200`.

**Q3.** If `a − b = 4` and `ab = 5`, find `a² + b²`.
(a) 26  (b) 16  (c) 21  (d) 36
**Answer: (a) 26**
*Solution:* `a² + b² = (a − b)² + 2ab = 4² + 2(5) = 16 + 10 = 26`.

**Q4.** If `x + 1/x = 4`, find `x² + 1/x²`.
(a) 14  (b) 16  (c) 18  (d) 12
**Answer: (a) 14**
*Solution:* `x² + 1/x² = (x + 1/x)² − 2 = 4² − 2 = 16 − 2 = 14`.

**Q5.** Solve `3x + 5 = 20`.
(a) 5  (b) 3  (c) 15  (d) 4
**Answer: (a) 5**
*Solution:* `3x = 20 − 5 = 15`, so `x = 15/3 = 5`.

## MEDIUM

**Q6.** If `x + 1/x = 5`, find `x³ + 1/x³`.
(a) 110  (b) 125  (c) 100  (d) 95
**Answer: (a) 110**
*Solution:* `x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 5³ − 3(5) = 125 − 15 = 110`.

🔑 *Trick:* For cubes use `x³ + 1/x³ = x³_val − 3·x` where x is the given sum.

**Q7.** If `a + b + c = 0`, the value of `a³ + b³ + c³` is:
(a) `3abc`  (b) `0`  (c) `abc`  (d) `a³b³c³`
**Answer: (a) 3abc**
*Solution:* When `a + b + c = 0`, the identity `a³ + b³ + c³ − 3abc = (a + b + c)(…)` gives RHS = 0, so `a³ + b³ + c³ = 3abc`.

**Q8.** If `a = 2 + √3`, find `a + 1/a`.
(a) 4  (b) 2√3  (c) 2  (d) 3
**Answer: (a) 4**
*Solution:* `1/a = 1/(2 + √3) = (2 − √3)/[(2+√3)(2−√3)] = (2 − √3)/(4 − 3) = 2 − √3`. So `a + 1/a = (2 + √3) + (2 − √3) = 4`.

**Q9.** If `x − 1/x = 3`, find `x² + 1/x²`.
(a) 11  (b) 7  (c) 9  (d) 13
**Answer: (a) 11**
*Solution:* `x² + 1/x² = (x − 1/x)² + 2 = 3² + 2 = 9 + 2 = 11`.

**Q10.** Factorise `8a³ + 27b³`.
(a) `(2a + 3b)(4a² − 6ab + 9b²)`  (b) `(2a + 3b)(4a² + 6ab + 9b²)`  (c) `(2a − 3b)(4a² + 6ab + 9b²)`  (d) `(2a + 3b)(4a² + 9b²)`
**Answer: (a) (2a + 3b)(4a² − 6ab + 9b²)**
*Solution:* `8a³ + 27b³ = (2a)³ + (3b)³ = (2a + 3b)[(2a)² − (2a)(3b) + (3b)²] = (2a + 3b)(4a² − 6ab + 9b²)`.

**Q11.** Solve the system: `x + y = 10`, `x − y = 4`. Find `x`.
(a) 7  (b) 6  (c) 5  (d) 8
**Answer: (a) 7**
*Solution:* Adding: `2x = 14`, so `x = 7` (and `y = 3`).

## HARD

**Q12.** If `x + 1/x = √5`, find `x³ + 1/x³`.
(a) `2√5`  (b) `5√5`  (c) `√5`  (d) `3√5`
**Answer: (a) 2√5**
*Solution:* `x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = (√5)³ − 3√5 = 5√5 − 3√5 = 2√5`.

**Q13.** If `a + b + c = 6` and `a² + b² + c² = 14`, find `ab + bc + ca`.
(a) 11  (b) 12  (c) 10  (d) 14
**Answer: (a) 11**
*Solution:* `(a + b + c)² = a² + b² + c² + 2(ab + bc + ca)`, so `36 = 14 + 2(ab+bc+ca)`, giving `2(ab+bc+ca) = 22`, hence `ab + bc + ca = 11`.

**Q14.** If `a² + b² + c² = ab + bc + ca`, then which is true?
(a) `a = b = c`  (b) `a + b + c = 0`  (c) `abc = 1`  (d) `a = b ≠ c`
**Answer: (a) a = b = c**
*Solution:* `a² + b² + c² − ab − bc − ca = ½[(a−b)² + (b−c)² + (c−a)²] = 0`. Each square must be 0, so `a = b = c`.

🔑 *Trick:* Recognise `a²+b²+c² = ab+bc+ca` instantly as the "all equal" signature.

**Q15.** If `x = 7 − 4√3`, find `√x + 1/√x`.
(a) 4  (b) 2√3  (c) 2  (d) 14
**Answer: (a) 4**
*Solution:* `7 − 4√3 = 4 − 4√3 + 3 = (2 − √3)²`, so `√x = 2 − √3`. Then `1/√x = 2 + √3` (rationalising). Sum `= (2 − √3) + (2 + √3) = 4`.

## SSC PYQ PATTERN

**Q16.** (SSC CGL pattern) If `x + 1/x = 6`, find `x² + 1/x²`.
(a) 34  (b) 36  (c) 38  (d) 32
**Answer: (a) 34**
*Solution:* `x² + 1/x² = 6² − 2 = 36 − 2 = 34`.

**Q17.** (SSC CGL pattern) If `2x + 3y = 13` and `5x + 2y = 16`, find `x`.
(a) 2  (b) 3  (c) 4  (d) 1
**Answer: (a) 2**
*Solution:* From eq1 × 2: `4x + 6y = 26`; eq2 × 3: `15x + 6y = 48`. Subtract: `11x = 22`, so `x = 2`.

**Q18.** (SSC CGL pattern) If `a³ + b³ = 152` and `a + b = 8`, find `ab`.
(a) 15  (b) 16  (c) 12  (d) 18
**Answer: (a) 15**
*Solution:* `a³ + b³ = (a + b)³ − 3ab(a + b)`, so `152 = 512 − 24ab`, giving `24ab = 360`, hence `ab = 15`.

**Q19.** (SSC CGL pattern) If `x = 1/(2 − √3)`, find `x² − 4x + 1`.
(a) 0  (b) 1  (c) 2  (d) −1
**Answer: (a) 0**
*Solution:* `x = 1/(2 − √3) = 2 + √3`, so `x − 2 = √3`, squaring `x² − 4x + 4 = 3`, thus `x² − 4x + 1 = 0`.

🔑 *Trick:* When asked for `x² − 4x + 1` style values, rearrange the surd so squaring eliminates the root.

### 🔑 Exam Tricks Box

- Memorise the four "sum/difference" conversions: `a²+b² = (a+b)² − 2ab` and the `±1/x` versions — they cover 60% of algebra questions.
- For `a + 1/a = x` problems, never find `a`; jump straight to `x² − 2` (squares) or `x³ − 3x` (cubes).
- `a + b + c = 0 ⇒ a³ + b³ + c³ = 3abc` is a one-line shortcut SSC loves.
- Spot perfect-square surds like `7 − 4√3 = (2 − √3)²` to crack root problems in seconds.

> ✅ Practice these patterns until identity recognition is instant — Algebra is the highest-ROI Quant topic in SSC CGL.
