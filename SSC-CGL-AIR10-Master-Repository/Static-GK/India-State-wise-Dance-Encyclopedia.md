# India State-wise Dance Encyclopedia

## Project Objective

This document provides a structured starter framework for an exam-oriented Indian dance encyclopedia useful for SSC, UPSC, State PSC, Banking, Railways, and cultural studies.

## Scope

- Cover all 28 states and 8 union territories
- Include classical, folk, tribal, ritual, martial, harvest, temple, and festival dances
- Add exam-friendly one-liners and current-affairs updates
- Build a workbook and CSV export for revision

## Phase-wise Plan

### Phase 1 – Data Collection

- List all 28 states and 8 union territories
- Verify official spellings
- Assign geographical region

### Phase 2 – Dance Forms

Collect dance forms across categories:

- Classical
- Folk
- Tribal
- Ritual
- Martial
- Harvest
- Temple
- Festival
- Community-specific
- Regional
- Newly recognized cultural dances

### Phase 3 – Dancer Database

Collect famous performers, Padma Awardees, Sangeet Natak Akademi awardees, living legends, and recent internationally recognized artists.

### Phase 4 – Recent Current Affairs (2025–2026)

Include national festivals, Guinness records, UNESCO updates, government cultural initiatives, Republic Day tableaux, and awards.

### Phase 5 – Exam Notes

For each dance form capture:

- State
- Category
- Community
- Festival
- Costume
- Musical instruments
- Occasion
- One-line SSC note

### Phase 6 – Excel Workbook

Planned sheets:

1. Master Database
2. State-wise Summary
3. Classical Dances
4. Folk Dances
5. Tribal Dances
6. Important Dancers
7. UNESCO Heritage
8. Recent Current Affairs
9. SSC One-Liners
10. MCQ Practice
11. Revision Tables

### Phase 7 – Excel Features

Filters, search, freeze panes, color coding, hyperlinks, dropdown filters, and sorting by state or category.

### Phase 8 – CSV Files

Separate CSV exports for:

- Master Database
- Dancers
- Current Affairs
- State Summary

### Phase 9 – Quality Check

Verify spellings, duplicates, states/UTs, current affairs, and SSC relevance.
