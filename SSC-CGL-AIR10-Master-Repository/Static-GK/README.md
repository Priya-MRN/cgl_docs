# Static GK — Master Bank

> Quick links: [GK Revision Cheat Sheet](../Cheat-Sheets/GK_Revision_Cheat_Sheet.md) · [Repository Home](../README.md)

This is the master bank of high-yield Static General Knowledge for SSC CGL. Each file contains dense quick notes, ~15 MCQs, ~5 SSC-pattern PYQ-style questions, and a compact revision sheet.

> **Weightage** (per the [PYQ Pattern Blueprint](../PYQ-Collection/PYQ-Pattern-Blueprint.md)): 🔴 High · 🟡 Medium · 🟢 Low repeat.
> SSC tests **fundamental concepts (Class 9–11 NCERT level)**, not obscure facts. Highest yield: History clusters, Polity (FR/FD/DPSP + amendments **42,44,73,74,86**), Geography basics, and **Science (the hidden gold mine)**. For Current Affairs, only 5 things matter: Awards, Govt Schemes, Sports, Important Days, Int'l Organizations — files 6–9 cover these.
