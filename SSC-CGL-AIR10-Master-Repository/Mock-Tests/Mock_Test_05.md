## Solutions & Explanations

**Reasoning**

- **Q1.** Each term doubles: 4→8→16→32→**64**.
- **Q2.** Letters mapped to alphabet position: S=19, N=14, O=15, W=23 → **19-14-15-23**.
- **Q3.** 8 (2³), 27 (3³), 64 (4³) are perfect cubes; **81** = 3⁴ is not a perfect cube.
- **Q4.** "Son of my mother" = Ravi himself (assuming the only son); his wife is Ravi's **Wife**.
- **Q5.** Gaps +4 each: D→H→L→P→**T**.
- **Q6.** Apply substitutions (+→×, −→+, ×→÷, ÷→−): 8 × 2 + 4 ÷ 2 − 3. BODMAS: 8×2 = 16, 4÷2 = 2 → 16 + 2 − 3 = **15**.
- **Q7.** Pattern n³: 3³ = 27, so 5³ = **125**.
- **Q8.** Each term doubles: 112 × 2 = **224**.
- **Q9.** Foundation → Walls → Roof → Door → Painting = **1, 3, 2, 4, 5**.
- **Q10.** Day after tomorrow is Friday → today is Wednesday. Yesterday = Tuesday; three days before Tuesday = **Saturday**.
- **Q11.** Position from right = (50 − 18) + 1 = **33rd**.
- **Q12.** Rule n² + n: 4² + 4 = 20, so 7² + 7 = 49 + 7 = **56**.
- **Q13.** Mango, Apple, Banana are fruits; **Potato** is a vegetable.
- **Q14.** C is mother of B; D is brother of C → D is B's uncle; B is A's parent → D is A's **Granduncle**.
- **Q15.** Each letter shifts +1: L→M, I→J, G→H, H→I, T→U gives LIGHT=MJHIU. Applying +1 to NIGHT: N→O, I→J, G→H, H→I, T→U → **OJHIU**.
- **Q16.** 13, 17, 19, 23 are primes; **21** = 3 × 7 is composite.
- **Q17.** Pattern n² − 1: 1−1, 4−1, 9−1, 16−1, 25−1, 36−1 = **35**.
- **Q18.** South 6, then left (East) 8 → right triangle → distance = √(6² + 8²) = √100 = **10 km**.
- **Q19.** All books → papers → white, so all books are white → **Valid**.
- **Q20.** © gives a × b − a: check 4×2−4 = 4 ✓, 6×3−6 = 12 ✓, 5×4−5 = 15 ✓ → 8 × 5 − 8 = 40 − 8 = **32**.
- **Q21.** Gaps +1, +2, +3, +4, +5: A→B→D→G→K→**P**.
- **Q22.** Pattern ×2 + 1: 3→7→15→31→63→**127**.
- **Q23.** A bird lives in a nest; a bee lives in a **hive**.
- **Q24.** In a 1×3 strip the rectangles = 3 + 2 + 1 = **6**.
- **Q25.** Factorial pattern (×2, ×3, ×4, ×5, ×6): 120 × 6 = **720**.

**Quantitative Aptitude**

- **Q51.** Speed = 180/9 = 20 m/s = 20 × 18/5 = **72 km/h**.
- **Q52.** 6 consecutive even numbers average 25 → average of 3rd & 4th = 25 → numbers 20,22,24,26,28,30 → largest **30**.
- **Q53.** 40% = 160 → number = 400; 75% of 400 = **300**.
- **Q54.** Four times in 15 yrs (SI) → interest = 3 × principal → R = 300/15 = **20%**.
- **Q55.** Difference 5−2 = 3 parts = 36 → one part = 12 → larger = 5 × 12 = **60**.
- **Q56.** CP 100 → MP 160 → 25% discount → SP = 120 → profit = **20%**.
- **Q57.** Form (a²+ab+b²) over (a³−b³) = 1/(a−b) = 1/(1.2 − 0.8) = 1/0.4 = **2.5**.
- **Q58.** 1/20 + 1/30 = 3/60 + 2/60 = 5/60 = 1/12 → time = **12 days**.
- **Q59.** CI = 5000(1.2² − 1) = 5000 × 0.44 = **₹2,200**.
- **Q60.** CP of 25 = SP of 20 → SP/CP = 25/20 = 1.25 → profit **25%**.
- **Q61.** Downstream = 24/2 = 12 km/h, upstream = 24/3 = 8 km/h → still water = (12+8)/2 = **10 km/h**.
- **Q62.** 2πr = 44 → r = 44 × 7/(2 × 22) = 44 × 7/44 = **7 cm**.
- **Q63.** BODMAS: 36÷6 = 6, 4×3 = 12 → 6 + 12 − 5 = **13**.
- **Q64.** SI = 4000 × 7.5 × 2 / 100 = **₹600**.
- **Q65.** Net factor 0.9 × 1.1 = 0.99 → **1% decrease**.
- **Q66.** Ratio 3:4:5 (12 parts) = 180° → one part = 15° → smallest = 3 × 15 = **45°**.
- **Q67.** From +15% to +10% is a 5% drop = ₹30 → 5% of CP = ₹30 → CP = **₹600**.
- **Q68.** 55² = 3025 → √3025 = **55**.
- **Q69.** Other = (LCM × HCF)/given = (144 × 12)/48 = **36**.
- **Q70.** Average speed = 2·50·30/(50+30) = 3000/80 = **37.5 km/h**.
- **Q71.** sin θ = 8/17 → 8-15-17 right triangle → cos θ = 15/17 → **15/17**.
- **Q72.** Reduction = 20/(100+20) × 100 = 20/120 × 100 = **16⅔%**.
- **Q73.** Equal SP with +25%/−25% gives a loss = (25²)/100 = **6.25% loss**.
- **Q74.** 50% of 600 = 300; 30% of 300 = **90**.
- **Q75.** Side = √169 = 13 → perimeter = 4 × 13 = **52 cm**.
