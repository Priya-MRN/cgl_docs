## Solutions & Explanations

**Reasoning**

- **Q1.** Each term doubles: 5→10→20→40→80→**160**.
- **Q2.** Letters to position number: S=19, U=21, N=14; M=13, O=15, O=15, N=14 → **13-15-15-14**.
- **Q3.** 8, 27, 64 are perfect cubes (2³,3³,4³); **100** is not.
- **Q4.** "My father's only son" = the man himself; his wife is the woman → **Wife**.
- **Q5.** Gap +4 each: D→H→L→P→**T**.
- **Q6.** Apply (÷→+, ×→−, +→×): 8 + 4 − 2 × 3 → BODMAS: 2×3=6 → 8 + 4 − 6 = **6**.
- **Q7.** AC,EG step +4 in first letter; IK → next **MO**.
- **Q8.** Rule ×2−1: 4→7→13→25→49→**97** (49×2−1).
- **Q9.** Build order: Foundation → Walls → Roof → Door → Painting = **1, 3, 2, 4, 5**.
- **Q10.** Day after tomorrow Friday → today Wednesday → yesterday **Tuesday**.
- **Q11.** Position from left = (50 − 18) + 1 = **33rd**.
- **Q12.** Rule n²+2: 4²+2 = 18, so 7²+2 = **51**.
- **Q13.** Rose, Lotus, Jasmine are flowers; **Mango** is a fruit.
- **Q14.** X is son of Y; Z is father of Y → X is Z's **Grandson**.
- **Q15.** F=6,A=1,C=3,E=5 → letter positions. HEAD: H=8,E=5,A=1,D=4 → **8-5-1-4**.
- **Q16.** 13,17,19,23 are primes; **21 = 3×7** is not prime.
- **Q17.** Differences 5,10,15,20,25: 56+25 = **81**.
- **Q18.** South 6, then left = East 8 → distance = √(6²+8²) = √100 = **10 km**.
- **Q19.** "Some papers are pens" does not link books to pens → **Invalid**.
- **Q20.** Gaps +2,+3,+4,+5,+6: C→E→H→L→Q→**W**.
- **Q21.** Reverse alphabet, step −2: Y,W,U,S,**Q**.
- **Q22.** Rule a$b = a²+b²... 2²+3²=13 ✓, 3²+4²=25 ✓, 4²+5²=41 ✓ → 5²+6² = **61**.
- **Q23.** A bird lives in a nest; a bee lives in a **hive**.
- **Q24.** 2×2 grid rectangles = 9 (1×1:4, 1×2:2, 2×1:2, 2×2:1) → **9**.
- **Q25.** Cubes: 1,8,27,64,125,**216** (6³).
