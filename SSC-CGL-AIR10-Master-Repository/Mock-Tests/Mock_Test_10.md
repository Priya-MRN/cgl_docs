## Solutions & Explanations

**Reasoning**

- **Q1.** Each term doubles: 2→4→8→16→32→**64**.
- **Q2.** Each letter shifts +1: B→C, O→P, O→P, K→L → CPPL; apply to PAGE → P→Q, A→B, G→H, E→F = **QBHF**.
- **Q3.** 24, 36, 48 are multiples of 12; **50** is not.
- **Q4.** Brother of the girl's mother = her maternal **Uncle**.
- **Q5.** Gaps +2,+3,+4,+5,+6: B→D→G→K→P→**V**.
- **Q6.** Apply (+→×, ×→−, −→÷, ÷→+): 8 × 2 − 6 ÷ 3 + 4 → BODMAS: 8×2=16, 6÷3=2 → 16 − 2 + 4 = **18**.
- **Q7.** Pattern n³: 2³ = 8, so 3³ = **27**.
- **Q8.** Differences 1,2,3,4,5,6: 1→2→4→7→11→16→**22** (16+6).
- **Q9.** Tailoring order: Buy cloth → Measure → Cut → Sew → Wear = **3, 5, 1, 4, 2**.
- **Q10.** 45 days = 6×7+3 → 3 days after Wednesday = **Saturday**.
- **Q11.** Position from left = (30 − 12) + 1 = **19th**.
- **Q12.** Rule n(n+1): 2×3 = 6, so 5×6 = **30**.
- **Q13.** Apple, Mango, Banana are fruits; **Carrot** is a vegetable.
- **Q14.** P is Q's brother; Q is R's wife and S's mother → P is S's maternal **Uncle**.
- **Q15.** L=12,A=1,M=13,P=16 (letter positions). DESK: D=4,E=5,S=19,K=11 → **4-5-19-11**.
- **Q16.** 11,13,17,19 are primes; **27 = 3³** is not prime.
- **Q17.** Differences 5,7,9,11,13: 35+13 = **48**.
- **Q18.** East 12, left = North 5 → distance = √(12²+5²) = √169 = **13 km**.
- **Q19.** "Some vehicles are buses" does not link cars to buses → **Invalid**.
- **Q20.** Each term ×2 in position gap +1,+2,+4: A(1)→B(2)→D(4)→H(8)→**P(16)**.
- **Q21.** Reverse alphabet, step −3: X,U,R,O,**L**.
- **Q22.** Rule a!b = 2(a+b): 2(6+2)=16, 2(8+3)=22, 2(9+4)=26 → 2(10+5) = **30**.
- **Q23.** A library stores books; an arsenal stores **weapons**.
- **Q24.** A rectangle with both diagonals has 4 small triangles + 4 larger half-rectangle triangles = **8**.
- **Q25.** Perfect squares: 2²,3²,4²,5²,6²,**7² = 49**.

**Quantitative Aptitude**

- **Q58.** 1/24 + 1/8 = 1/24 + 3/24 = 4/24 = 1/6 → **6 days**.
- **Q59.** CI = 15000(1.1² − 1) = 15000 × 0.21 = **₹3,150**.
- **Q60.** CP of 25 = SP of 20 → SP/CP = 25/20 = 1.25 → profit **25%**.
- **Q61.** Downstream 48/4 = 12, upstream 48/6 = 8 → still water = (12+8)/2 = **10 km/h**.
