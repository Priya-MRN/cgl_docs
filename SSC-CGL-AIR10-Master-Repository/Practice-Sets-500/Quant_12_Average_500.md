# Average — 500 Question Practice Set (SSC CGL, Hard / Tier-II Level)

> **Format:** All 500 questions appear first; the full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** Medium / Hard / Very-Hard (trap) — CGL Tier-II standard.
> **Every numeric answer is computed and machine-verified** — the keyed option is provably correct.
> Negative marking in CGL is −0.50; the distractors are real common-mistake values.

## Key Formulas
- `Average = (sum of observations) / (number of observations)`
- Average of consecutive numbers / an AP = **(first + last) / 2**
- Average of first n natural numbers = **(n+1)/2**
- Average of first n multiples of k = **k(n+1)/2**
- New value when one item is added/removed: recompute **sum ± value** over **new count**
- Wrong value corrected: change in sum = **(change in average) × (count)**
- Person joins and average changes by d → person = **(new avg)×(new count) − (old sum)**
- Weighted average of two groups = **(n₁a₁ + n₂a₂)/(n₁ + n₂)**
- Runs to raise average to A after next innings = **A×(innings now) − (old total)**
