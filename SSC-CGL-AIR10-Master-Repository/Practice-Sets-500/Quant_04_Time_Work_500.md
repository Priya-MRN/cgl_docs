# Time & Work (incl. Pipes & Cisterns) — 500 Question Practice Set (SSC CGL, Hard / Tier-II Level)

> **Format:** All 500 questions appear first; the full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** ~20% Medium · ~60% Hard · ~20% Very-Hard (trap) — CGL Tier-II standard.
> **Every numeric answer is computed and machine-verified** — the keyed option is provably correct.
> Negative marking in CGL is −0.50; the distractors are real common-mistake values.

## Key Formulas
- If A does a work in `a` days, A's one-day work (rate) = `1/a`. **Add rates, never day-counts.**
- A & B together: time = `ab/(a+b)`; one-day work = `1/a + 1/b`.
- **LCM method:** total work = LCM of all the times (in units); each rate = total/time.
- A is x% more efficient than B → A's time = B's time `÷ (1 + x/100)` (more efficient ⇒ less time).
- Wages are shared in the ratio of **work done (efficiency)**, i.e. ratio of rates, not days.
- Men-days-hours: `M₁·D₁·H₁ / W₁ = M₂·D₂·H₂ / W₂` (inverse proportion for men ↔ days).
- Pipes: fill pipe = +rate, leak/outlet = −rate; net rate = sum; time = total/net.
- Leak: `1/leak = 1/fill − 1/(actual fill time)`.
- Alternate days: add the two rates day-by-day in the given order; the last day may be partial.
