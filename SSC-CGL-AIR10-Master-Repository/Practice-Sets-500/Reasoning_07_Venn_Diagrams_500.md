# Venn Diagrams / Logical Venn — 500 Question Practice Set (SSC CGL, Reasoning, Tier-I/II Level)

> **Format:** All 500 questions appear first; the full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** ~20% Medium · ~60% Hard · ~20% Very-Hard.
> **Every numeric answer is computed by inclusion–exclusion and machine-verified** — the keyed option is provably correct.
> Relationship-diagram items use curated, fact-checked class triples.
> Negative marking in CGL is −0.50; distractors are real common-mistake values.

## Quick Reference
- **2 sets:** n(A∪B) = n(A) + n(B) − n(A∩B);  Neither = Total − n(A∪B).
- **3 sets:** n(A∪B∪C) = Σn − Σpairwise + n(A∩B∩C).
- **Only A** = n(A) − n(A∩B) − n(A∩C) + n(A∩B∩C).
- **Exactly two** = Σpairwise − 3·n(A∩B∩C).  **Exactly one** = Σonly-regions.
- **Relationship diagrams:** decide nesting / disjoint / overlap from the real-world relation of the classes, then match the worded diagram.
