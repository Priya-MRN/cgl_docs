# Spelling & Cloze Test — 500 Question Practice Set (SSC CGL, PYQ Pattern)

> **Format:** All 500 questions appear first (Q1–Q250 Spelling, Q251–Q500 Cloze Test); the full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** ~20% Medium · ~60% Hard · ~20% Very-Hard — drawn from CGL Tier-I/Tier-II spelling and cloze PYQs repeated across 2018–2025.
> **Every item is hand-authored and fact-checked:** in Spelling exactly ONE option is correctly spelt (or, in 'misspelt' variants, exactly ONE is wrong); in Cloze exactly ONE option fits the blank's collocation, grammar and sense.
> **Read the prompt carefully:** some Spelling questions ask for the CORRECTLY spelt word and others ask for the MISSPELT word.
> Negative marking in CGL is −0.50 — for Cloze, read the whole passage before filling any blank so connectors and tense agree.
