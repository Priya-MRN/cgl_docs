# Order & Ranking - 500 Question Practice Set (SSC CGL, Reasoning / Tier-I & II Level)

> **Format:** All 500 questions appear first; the full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** ~20% Medium - ~60% Hard - ~20% Very-Hard (interchange / comparative ordering / minimum-total) - CGL standard.
> **Every arrangement is modelled on an explicit row (position 1 = left/top end) or a brute-force-verified unique order, and machine-verified** - the keyed option is provably correct.
> Negative marking in CGL is -0.50; distractors are real common-mistake values (forgetting the -1, swapping the two ends, taking an adjacent position).

## How order & ranking works (quick reference)
- Treat the row as positions numbered 1, 2, 3, ... from the LEFT (or TOP). Then position from the RIGHT (or BOTTOM) = total - (position from left) + 1.
- **Master identity:** if a person is n-th from one end and m-th from the other end, then total = n + m - 1 (subtract 1 so the person is not counted twice).
- **Persons between** two people measured from the same end = |position1 - position2| - 1.
- **Interchange:** when A and B swap seats, A takes B's old position and vice-versa; then apply the identities to the new positions.
- **Comparative ordering** (tallest/oldest/heaviest): chain the clues into one total order, e.g. A > B > C > D, then read off the required rank. Here every such order is brute-force checked to be the ONLY arrangement consistent with the clues.
- **Minimum total** when c persons sit between someone n-th from the left and someone m-th from the right (non-overlapping) = n + c + m.
