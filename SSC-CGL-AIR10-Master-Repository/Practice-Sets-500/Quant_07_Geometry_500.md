## Key Formulas
- Triangle angle sum = 180 deg; exterior angle = sum of two remote interior angles
- Isosceles: base angles equal; apex = 180 - 2 x base
- Parallel lines + transversal: corresponding & alternate angles equal; co-interior (allied) supplementary
- Basic Proportionality (Thales): DE || BC => AD/DB = AE/EC
- Similar triangles: ratio of areas = (ratio of sides)^2
- Pythagoras: hyp^2 = leg1^2 + leg2^2 (triples 3-4-5, 5-12-13, 8-15-17, 7-24-25, 9-40-41)
- Circle: angle at centre = 2 x inscribed angle on same arc; angle in semicircle = 90 deg
- Cyclic quadrilateral: opposite angles supplementary (sum 180 deg)
- Two tangents from a point: angle between tangents + angle at centre = 180 deg
- Tangent length = sqrt(OP^2 - r^2); perpendicular from centre bisects a chord
- Centroid divides each median 2:1 from the vertex
- Incentre angle: angle BIC = 90 + A/2
- Polygon: sum of interior angles = (n-2) x 180; each exterior angle (regular) = 360/n
- Coordinates: distance = sqrt(dx^2 + dy^2); midpoint = ((x1+x2)/2,(y1+y2)/2)
- Section formula: x = (m x2 + n x1)/(m+n); Area = (1/2)|x1(y2-y3)+x2(y3-y1)+x3(y1-y2)|
