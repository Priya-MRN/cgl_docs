## Key Formulas
- **Mean** = (Σx)/n  ·  **Grouped/Weighted mean** = Σ(f·x)/Σf
- **Median:** sort the data. Odd n → middle value; even n → average of the two middle values.
- **Mode** = the value occurring most frequently.
- **Range** = maximum − minimum.
- **Combined mean** = (n₁m₁ + n₂m₂)/(n₁ + n₂).
- **Population variance** = Σ(x − mean)²/n  ·  **SD** = √variance.
- **SD of first n natural numbers** = √((n² − 1)/12).
- **Transforms:** new value = a·x + b ⇒ mean → a·mean + b ; SD → |a|·SD (adding b does not change SD).
- **Quartiles:** Q1 = median of lower half, Q3 = median of upper half; **IQR** = Q3 − Q1.
- **Empirical relation:** Mode = 3·Median − 2·Mean.
