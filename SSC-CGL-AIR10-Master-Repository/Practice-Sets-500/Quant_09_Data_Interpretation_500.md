# Data Interpretation - 500 Question Practice Set (SSC CGL, Hard / Tier-II Level)

> **Format:** Questions come in SETS - a data block (table/bar/pie/line) followed by 5 sub-questions. Questions are numbered Q1-Q500 continuously. The full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** ~20% Medium / ~60% Hard / ~20% Very-Hard (trap) - CGL Tier-II standard.
> **Every numeric answer is computed and machine-verified** - the keyed option is provably correct.
> Negative marking in CGL is -0.50; the distractors are real common-mistake values.

## How to read DI
- **Table:** read the row (category) and column (year) intersection for each cell.
- **Bar graph:** each label maps to a value, given here as a `label=value` list.
- **Pie chart:** each slice is a percent of the stated total; actual value = percent/100 x total.
- **Line/mixed:** two series (e.g. Imports & Exports) tabulated by year.
- Common asks: total/average over a row or column, ratio between two cells, what percent one is of another, percent increase/decrease between years, difference, highest/lowest, combined-category totals, average excluding one item.
