# Time, Speed & Distance (incl. Trains, Boats & Streams) — 500 Question Practice Set (SSC CGL, Hard / Tier-II Level)

> **Format:** All 500 questions appear first; the full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** ~20% Medium · ~60% Hard · ~20% Very-Hard (trap) — CGL Tier-II standard.
> **Every numeric answer is computed and machine-verified** — the keyed option is provably correct.
> Negative marking in CGL is −0.50; the distractors are real common-mistake values.

## Key Formulas
- Speed = Distance / Time  ·  Distance = Speed × Time  ·  Time = Distance / Speed
- km/h → m/s: **× 5/18**  ·  m/s → km/h: **× 18/5**
- Average speed over two EQUAL distances at x, y = **2xy/(x+y)** (harmonic mean, NOT (x+y)/2)
- Train crossing a pole: time = length / speed
- Train crossing a platform: time = (length + platform) / speed
- Opposite directions: relative speed = **s₁ + s₂**  ·  Same direction: relative speed = **s₁ − s₂**
- Boats: downstream = b + s, upstream = b − s  ·  b = (down+up)/2, s = (down−up)/2
- Speed ↑ x% → time decreases by **x/(100+x)×100 %**
- Stoppage time/hour = **(a−b)/a × 60** minutes (a = speed w/o stops, b = with stops)
