## IMPORTANT — how the (un-drawable) figures are represented in text
Figures cannot be drawn in markdown, so this set covers only the **text-representable, exactly computable** part of Non-Verbal Reasoning. The conventions below are fixed and used consistently throughout:

- **Mirror Image (vertical mirror):** A mirror held along a *vertical* line reverses the **left-to-right order** of the characters. To make every glyph behave exactly, mirror-image questions use only letters/digits that are **left-right symmetric** — A, H, I, M, O, T, U, V, W, X, Y and 0, 1, 8 — so each glyph is unchanged and ONLY the order flips. Thus mirror(`WAX`) = `XAW`.
- **Water Image (horizontal mirror):** A reflection *in water* is about a *horizontal* line; it flips each glyph **top-to-bottom** while keeping the left-to-right order. Water-image questions use only **top-bottom symmetric** glyphs — B, C, D, E, H, I, K, O, X and 0, 1, 3, 8 — so each glyph is unchanged and the whole string stays the same.
- **Dice:** a standard cube with faces numbered 1–6. A 'view' names the three faces meeting at one corner (top, front, right). Two views, or two stated opposite pairs, are enough to deduce the remaining opposite pair exactly.
- **Counting figures:** each figure is described precisely in words and the total is given by a closed-form formula (squares in an n×n grid = 1²+2²+…+n²; rectangles in an m×n grid = C(m+1,2)·C(n+1,2); triangles in a subdivided triangle = n(n+2)(2n+1)/8 type formula; a base split into s parts and joined to the apex = s(s+1)/2 triangles).
- **Paper folding & punching:** folding a square in half f times makes 2^f layers; p punches through all layers give p·2^f holes when unfolded.
- **Series / Analogy:** letter-strings transformed by an exact rule (fixed alphabet shift, reversal, or left-rotation).
- **Embedded figures:** the 'figure' is a linear string of symbols; the task is to count or detect a contiguous sub-pattern.
