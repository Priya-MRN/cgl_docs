# HCF & LCM — 500 Question Practice Set (SSC CGL, Hard / Tier-II Level)

> **Format:** All 500 questions appear first; the full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** ~20% Medium · ~60% Hard · ~20% Very-Hard (trap) — CGL Tier-II standard.
> **Every numeric answer is computed and machine-verified** — the keyed option is provably correct.
> Negative marking in CGL is −0.50; the distractors are real common-mistake values.

## Key Formulas
- **Product of two numbers = HCF × LCM** → other number = (HCF × LCM)/one number
- LCM(a, b) = (a × b)/HCF(a, b)
- Numbers in ratio p:q (co-prime) with HCF h → numbers are hp, hq; LCM = h·p·q
- Greatest number dividing a, b, c leaving remainders r1, r2, r3 = **HCF(a−r1, b−r2, c−r3)**
- Greatest number dividing a, b, c leaving the **same** remainder = **HCF of the differences**
- Least number leaving remainder r when divided by a, b, c = **LCM(a,b,c) + r**
- Least number leaving remainders (a−k),(b−k),(c−k) = **LCM(a,b,c) − k**
- HCF of fractions = **HCF(numerators)/LCM(denominators)**
- LCM of fractions = **LCM(numerators)/HCF(denominators)**
- Bells toll together every LCM seconds; count in T = T/LCM + 1 (include the start)
- Least square tiles for L×B floor = (L×B)/HCF(L,B)²
