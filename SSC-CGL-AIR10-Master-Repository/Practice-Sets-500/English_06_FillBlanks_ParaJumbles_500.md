# Fill in the Blanks & Para Jumbles — 500 Question Practice Set (SSC CGL, PYQ Pattern)

> **Format:** All 500 questions appear first (Q1–Q250 Fill in the Blanks, Q251–Q500 Para Jumbles); the full **Answer Key & Explanations** is at the very end.
> **Difficulty skew:** ~20% Medium · ~60% Hard · ~20% Very-Hard — CGL Tier-I/Tier-II sentence-completion and sentence-ordering repeated across PYPs 2018–2025.
> **Every item is hand-authored and verified:** exactly ONE option is correct; for fills the distractors are real words that break the collocation/grammar, and each para jumble has a single coherent logical order.
> **Fill in the Blanks** test vocabulary collocations, prepositions, conjunctions, and tense; **Para Jumbles** test logical, chronological, and pronoun-reference cues.
> Negative marking in CGL is −0.50 — read the stem (a SINGLE blank, DOUBLE blanks, or a sentence-ORDER) before marking.
