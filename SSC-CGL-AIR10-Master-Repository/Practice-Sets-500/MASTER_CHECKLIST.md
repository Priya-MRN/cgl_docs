# SSC CGL — 500-Question Practice Sets · Master Checklist

> Goal: For **every topic in the SSC CGL 2026 syllabus**, build a set of **500 hard, CGL-standard MCQs**.
> Format per topic file: **all 500 questions first**, then **all 500 answers + explanations at the end**.
> Difficulty skew: **~20% Medium · ~60% Hard · ~20% Very-Hard (Tier-II trap level)**.
> Hard rule: **every answer key independently re-solved / fact-checked. Zero errors in questions or options.**

---

## How each set is built (the process — repeat for every topic)

1. **Draft 500 questions** in blocks of 50 (Q1–Q50, Q51–Q100, …) with 4 options each.
2. **Answers section** at the end: every question re-stated by number with **Answer + worked solution**.
3. **Quality check (mandatory before marking ✅):**
   - Re-solve every Quant numeric independently; the keyed option must exist and be unique.
   - No two options identical; exactly one correct option; distractors are *plausible* (common-mistake values).
   - GA/English: fact verified; no ambiguous "two correct" items.
   - Difficulty audited against the 20/60/20 skew.
   - No duplicate questions within the set.
4. Mark the row ✅ only after the quality check passes.

See `_TEMPLATE_AND_STANDARDS.md` for the exact file layout and question-writing rules.
