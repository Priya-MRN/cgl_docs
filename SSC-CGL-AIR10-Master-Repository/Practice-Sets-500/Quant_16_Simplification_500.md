> **Every numeric answer is computed by exact `Fraction` arithmetic and machine-verified** — the keyed option is provably correct.
> Negative marking in CGL is −0.50; the distractors are real common-mistake values.

## Key Formulas
- **BODMAS order:** Brackets → Of/Orders (powers, roots) → Division → Multiplication → Addition → Subtraction.
- Brackets are resolved innermost first:  `( )` → `{ }` → `[ ]`.
- **'of' means ×:**  `a/b of N = a/b × N`.
- `a² − b² = (a − b)(a + b)`  →  `(a²−b²)/(a−b) = a + b`.
- **Surds:** `√a × √b = √(ab)`,  `√(a/b) = √a / √b`.
- **Rationalise:** `1/(√a + √b) = (√a − √b)/(a − b)`.
- **Indices:** `xᵃ · xᵇ = xᵃ⁺ᵇ`,  `(xᵃ)ᵇ = xᵃᵇ`,  `xᵃ ÷ xᵇ = xᵃ⁻ᵇ`.
- Repeated `√` of a perfect power halves the exponent each time.
