## Key Formulas
- `x² + 1/x² = (x + 1/x)² − 2 = (x − 1/x)² + 2`
- `x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x)`  ·  `x³ − 1/x³ = (x − 1/x)³ + 3(x − 1/x)`
- `x⁴ + 1/x⁴ = (x² + 1/x²)² − 2`
- `a² + b² = (a + b)² − 2ab`  ·  `a³ + b³ = (a + b)³ − 3ab(a + b)`
- `(a − b)² = (a + b)² − 4ab`
- `a² + b² + c² = (a + b + c)² − 2(ab + bc + ca)`
- If `a + b + c = 0` then `a³ + b³ + c³ = 3abc`
- `a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)`
- **Factor/Remainder theorem:** remainder of p(x) ÷ (x − r) is p(r); (x − r) is a factor ⇔ p(r) = 0
- **Componendo & dividendo:** if a/b = p/q then (a + b)/(a − b) = (p + q)/(p − q)
- **AM–GM:** for x > 0, x + k/x ≥ 2√k
