# 500-Set File Template & Question-Writing Standards

Every topic file in `Practice-Sets-500/` MUST follow this exact layout.

## File layout

```
# <Topic> — 500 Question Practice Set (SSC CGL, Hard / Tier-II Level)

> Format: Questions Q1–Q500 first. Answers + explanations at the very end.
> Difficulty: ~20% Medium · ~60% Hard · ~20% Very-Hard.
> Negative marking in CGL is −0.50 — distractors below are real common-mistake traps.

## Key Formulas / Quick Reference   (Quant topics only)
...

# ===================  QUESTIONS  ===================

## Block 1 (Q1–Q50)
**Q1.** ...
(a) ...  (b) ...  (c) ...  (d) ...
...

# ===================  ANSWER KEY & EXPLANATIONS  ===================

## Answers Q1–Q50
**Q1. (c)** — worked solution / reason.
...
```

## Question-writing rules (so we never produce a wrong key)

1. **Quant:** Choose the numbers first, compute the exact answer, THEN write the 4 options. The correct value must be placed at a varied position (don't always make it (b)). Distractors = the values you'd get from the 3 most common mistakes (wrong formula direction, off-by-base%, sign slip).
2. **One and only one** option is correct. Never two equivalent options.
3. **Options must be distinct** and in a sensible order (ascending for numerics where natural).
4. **No "All/None of the above"** unless genuinely the cleanest form.
5. **GA:** one verifiable fact per question; avoid anything that has changed recently unless it's settled. Prefer constitutional articles, fixed historical dates, definitions.
6. **English Error Spotting:** exactly one grammatical error; the "No error" option appears but is used sparingly and correctly.
7. **Hard skew:** prefer multi-step problems, successive operations, ratio+percentage combos, traps that punish the obvious shortcut.
8. **Verification:** after a block is written, independently re-solve each item. Fix any mismatch before moving on.

## Difficulty tags (used in the answer key, optional inline)
- `[M]` Medium · `[H]` Hard · `[VH]` Very-Hard trap
