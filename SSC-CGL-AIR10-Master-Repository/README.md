> A structured, PYQ-oriented, revision-first preparation system for **SSC CGL 2026**.
> Built for a working professional with ~2 months runway, starting from beginner, targeting **AIR-level** scores.

**Exam date target:** ~2 months from start · **Daily commitment:** 6 hrs (see plan below)

---

## How to Use This Repository

1. **Start every day with a Formula/Cheat Sheet** (10 min warm-up recall).
2. **Solve from the Master Banks** — never just read; always solve, then check the explanation.
3. **Mark every wrong question** with a ✗ in your own notes and re-solve weekly.
4. **In the last 30 days**, switch to the [Revision Notes](Revision-Notes/) + [Mock Tests](Mock-Tests/).
5. **High Repeat PYQs** in the [PYQ Collection](PYQ-Collection/) are the single highest-ROI content — master these first.
